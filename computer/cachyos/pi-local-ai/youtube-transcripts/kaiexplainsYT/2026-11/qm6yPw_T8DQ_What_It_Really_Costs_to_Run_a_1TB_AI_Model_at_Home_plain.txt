Now, before we get to the actual price numbers, I need to explain one piece of technical reality because without it, the costs don't make intuitive sense. And I promise this won't hurt. You might reasonably think that a model like Mixtral open, which uses 42 billion parameters per token, would only need 42 billion parameters worth of memory. If it uses 42 billion, it should need 42 billions worth of space, which sounds like clean math, right? But that's not how these models actually work. All three of these models use an architecture called mixture of experts. Instead of one giant generalist network, the model is actually hundreds of small specialist networks called experts. And for every single token, a router picks a handful of those experts to handle the job, and only those experts do the actual computation. Mixtral open has 42 billion active parameters, but it's choosing those from a pool of 816 billion spread across hundreds of experts. And Kimi K3.1 Pro has 896 experts in total and uses 16 at a time. The catch is that the next token might pick a completely different set of experts, and the token after that a different set again. So every single expert, all 816 billion parameters worth, has to be sitting in fast memory the whole time waiting to be called, which is like keeping a whole warehouse stocked even if you're only pulling from a few shelves per order. Then for each token, the chip reads those chosen experts out of memory, does the computation and throws it away, and then it reads again thousands of times per answer. There's a name for this in computer engineering, which is memory-bound decoding. If your memory is the warehouse, then memory bandwidth, meaning how fast data moves from storage to the processor, is the width of the loading dock. The other thing this architecture means is that total parameter count decides how much memory you need to buy, but it's the active parameters divided by your memory bandwidth that decides how fast it runs.
